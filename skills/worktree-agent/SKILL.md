# worktree-agent — Git Isolation Protocol

Isolate every coding sub-agent in its own git worktree. No more race conditions. Every change becomes a PR.

## When to Use

**USE** when launching a sub-agent that will:
- Modify source code files
- Touch more than 2 files
- Run `sdd-apply` or similar write-heavy phases

**SKIP** when:
- Sub-agent is read-only (explore, verify, search)
- Working in a non-git directory
- User explicitly says "work in current directory"

## Setup Protocol (Before Launching Sub-Agent)

```bash
# 1. Generate unique worktree ID
WID=$(cat /proc/sys/kernel/random/uuid | cut -c1-8)
CHANGE_SLUG=$(echo "{change-name}" | tr '[:upper:]' '[:lower:]' | tr ' ' '-')
BRANCH="agent/${CHANGE_SLUG}-${WID}"
WORKTREE="/tmp/wt-${WID}"

# 2. Verify we're in a git repo
git rev-parse --git-dir > /dev/null 2>&1 || { echo "Not a git repo — skipping worktree isolation"; exit 0; }

# 3. Create worktree on new branch
git worktree add "$WORKTREE" -b "$BRANCH"

echo "Worktree: $WORKTREE"
echo "Branch:   $BRANCH"
```

## Sub-Agent Launch Instructions

When launching the sub-agent, include in the prompt:

```
WORKTREE ISOLATION ACTIVE:
- Your working directory is: {WORKTREE_PATH}
- All file reads/writes must use absolute paths under {WORKTREE_PATH}
- Branch: {BRANCH_NAME}
- When done, output: "WORKTREE_DONE: {WORKTREE_PATH}"
- Do NOT run git commands — the orchestrator handles commit/PR
```

## Teardown Protocol (After Sub-Agent Returns)

```bash
# 1. Check for changes
cd "$WORKTREE"
CHANGED=$(git status --porcelain)

if [ -n "$CHANGED" ]; then
  # 2. Stage and commit
  git add -A
  git commit -m "$(cat <<EOF
agent: {change-name}

Auto-generated by worktree-agent.
Change: {change-name}
Worktree: $WID
EOF
)"

  # 3. Push branch
  git push -u origin "$BRANCH"

  # 4. Open PR
  gh pr create \
    --title "agent: {change-name}" \
    --body "$(cat <<EOF
## Summary
Auto-generated by worktree-agent for change: **{change-name}**

## Changes
$(git diff --stat HEAD~1)

## How to review
\`\`\`bash
gh pr checkout {pr-number}
\`\`\`
EOF
)" \
    --base main

  PR_URL=$(gh pr view --json url -q .url)
  echo "PR opened: $PR_URL"
else
  echo "No changes detected — skipping PR"
fi

# 5. Cleanup
cd ~
git worktree remove "$WORKTREE" --force 2>/dev/null || true
git branch -d "$BRANCH" 2>/dev/null || true
```

## Error Handling

If `git worktree add` fails (e.g. branch already exists):
```bash
git worktree add "$WORKTREE" -b "${BRANCH}-2"
```

If `gh pr create` fails (not authenticated or no remote):
- Keep the branch
- Report the branch name to the user
- User can manually push and open PR

## Status Report Format

```
## Worktree Agent Report

Setup:    ✅ Worktree created at {path}
Branch:   agent/{change-slug}-{wid}
Changes:  {n} files modified

Teardown: ✅ Committed + pushed
PR:       {url} or "❌ No changes"

Cleanup:  ✅ Worktree removed
```
